# Portfolio

The personal portfolio of Subrat Shah, a Senior Software Engineer working on Android with Kotlin and Jetpack Compose.

Live at https://subratshah.github.io/

It presents my experience at PayPal, Ford and Infosys as short case studies, each paired with a phone mock that shows the matching app screen as you scroll. It also covers my skill stack, education, awards, projects and how to reach me.

It is a plain static site: HTML, CSS and a little vanilla JavaScript, with no framework and no build step. It rarely needs updating, so I kept it that simple on purpose.

The case studies describe my own contribution and the engineering decisions behind it. They leave out confidential product and company details.
